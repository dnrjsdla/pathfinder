# 파이썬 가상환경

프로젝트마다 `.venv` 하나. 전역에 설치하면 버전이 프로젝트끼리 충돌한다.

- `python -m venv .venv` 로 만들고 `.venv/bin/python` 을 **직접 경로로** 부른다.
- `activate` 는 셸 상태를 바꾸므로 스크립트나 에이전트에서는 안 쓰는 편이 안전하다.
- `pip install -e .` 는 소스를 그 자리에서 import 하게 만든다. 사본을 만들지 않는다.
- editable 설치는 만든 **그 경로**를 가리킨다. 폴더를 복사해도 import 는 원본으로 간다.
- 인터프리터 버전을 올리면 `.venv` 를 지우고 다시 만든다.

`requirements.txt` 대신 `pyproject.toml` 을 쓰면 의존성과 빌드 설정이 한 파일에 있다.
